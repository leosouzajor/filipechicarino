Este é um artigo temporário criado para validar o funcionamento completo do novo sistema editorial do site.

## Teste de publicação

O objetivo deste conteúdo é confirmar que um artigo criado diretamente pelo Pages CMS consegue percorrer todo o fluxo de publicação **sem qualquer edição manual de código**.

Durante este teste, vamos verificar:

- criação automática do arquivo Markdown;

- upload da imagem de capa;

- geração da página do artigo;

- inclusão na página do Blog;

- inclusão no sitemap;

- geração dos metadados de SEO;

- publicação na branch de produção.

> Se você está lendo este texto na versão gerada do site, o pipeline editorial funcionou corretamente.

Este conteúdo será removido assim que todos os testes forem concluídos.
